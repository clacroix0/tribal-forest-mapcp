NoData: excluded from cover-type polygons; preserved as holes/gaps and
separately counted in QC. This slice does not export a separate NoData layer.
Unknown VALID values (7, 8, 255) remain distinct polygon categories.

Evidence-attribute limitation:
class_source_evt_codes is the list POSSIBLE for a class from the codebook,
not the actual source EVT codes measured inside an individual patch.
Review flags are a conservative union of the approved class-level flags;
review_flag_scope records this. Actual patch-level source EVT/EVC/EVH
summaries are not produced in this bounded draft.

If validation fails before writing, the command returns a structured failure.
If a write/read-back fails after creating a run folder, it returns failure
and attempts to create FAILED_DO_NOT_USE.json. Do not use a partial GeoPackage.
No automatic geometry repair is attempted.
